🧩 Example 1 — Using @OneToMany (if AddressOfUsers is an entity)
If each user can have multiple addresses stored as separate entities:
 ------------------------------------------------------------------------------------------
@Entity
@Table(name = "users")
public class User {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;

    // ✅ Correct mapping for entity collection
    @OneToMany(mappedBy = "user", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<AddressOfUsers> addresses = new ArrayList<>();

    // getters and setters
}

-----------------------------------------------------------------------------
@Entity
@Table(name = "users")

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;

    // ✅ Correct mapping for basic collection

✅ Summary
-> Use @OneToMany if AddressOfUsers is an entity with its own table.
-> Use @ElementCollection + @Embeddable if it’s just a value object.
-> Make sure the package and imports are correct (jakarta.persistence.* or javax.persistence.* depending on your Spring Boot version).
